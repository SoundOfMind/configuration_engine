# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues or Discussions.

If you believe you have found a security vulnerability in Configuration Engine, please use GitHub's private vulnerability reporting feature for this repository.

When reporting a vulnerability, please include:

- A description of the vulnerability
- The affected component or feature
- Steps to reproduce the problem, if possible
- Any relevant configuration or environment information
- The potential impact of the vulnerability

Please allow time for the issue to be reviewed before publicly disclosing details.

## Supported Versions

Security fixes will be considered for the current public release of Configuration Engine.

Configuration Engine is an early-stage project. Older releases may not receive security fixes after a newer release is available.
